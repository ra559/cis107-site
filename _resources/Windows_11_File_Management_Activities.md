## Learning Objectives

By completing these activities, students will practice:

- Creating folders and files
- Navigating the Windows 11 file system
- Renaming files and folders
- Copying and moving files
- Using drag and drop
- Deleting and restoring files
- Searching for files
- Identifying file extensions
- Sorting and changing File Explorer views
- Organizing files into a logical folder structure


## Activity 1: Create a Folder Structure

**Skills:** Creating folders and navigating directories

Create the following folder structure inside your **Documents** folder:

``` text
CIS107
├── Assignments
├── Documents
├── Images
├── Projects
└── Downloads
```


### Tasks

1. Open **File Explorer**.
2. Open your **Documents** folder.
3. Create a folder named `CIS107`.
4. Open the `CIS107` folder.
5. Create the five subfolders shown above.
6. Navigate between the folders using File Explorer.
7. Use the address bar to navigate directly to the `CIS107` folder.

> Take a screenshot of File Explorer showing all the folders inside the CIS107 folder. Save your screenshot to use later in your final submission.


## Activity 2: Create and Rename Files

**Skills:** Creating and renaming files

Inside the `CIS107\Documents` folder, create three text files:

``` text
notes.txt
assignment.txt
important.txt
```

### Tasks

1.  Create `notes.txt`.
2.  Create `assignment.txt`.
3.  Create `important.txt`.
4.  Rename `assignment.txt` to `first_assignment.txt`.
5.  Rename `important.txt` to `important_notes.txt`.
6.  Change File Explorer to **Details** view.

### Final Files

The folder should contain:

``` text
notes.txt
first_assignment.txt
important_notes.txt
```

> Take a screenshot of File Explorer showing all the files inside the `CIS107\Documents` folder. Save your screenshot to use later in your final submission.


## Activity 3: Copy and Move Files

**Skills:** Copying, cutting, and pasting files

Use the files created in Activity 2.

### Tasks

1.  Copy `notes.txt` to the `Assignments` folder.
2.  Move `first_assignment.txt` to the `Assignments` folder.
3.  Leave `important_notes.txt` in the `Documents` folder.
4.  Verify that each file is in the correct location.

### Concepts

-   **Copy** creates another copy of a file.
-   **Move** changes the location of the existing file.
-   **Cut and Paste** can be used to move files.
-   **Copy and Paste** can be used to create copies.

> Take a screenshot of File Explorer showing all the files inside the `CIS107\Documents` folder and the `CIS107\Assignments` folder. You must take a single screenshot showing both folders. Save your screenshot to use later in your final submission.


## Activity 4: Practice Drag and Drop

**Skills:** Mouse operations and file manipulation

1.  Open two File Explorer windows.
2.  In the first window, open `CIS107\Documents`.
3.  In the second window, open `CIS107\Images`.
4.  Drag a file from one folder to the other.
5.  Repeat the operation while holding **Ctrl**.
6.  Observe the difference between the two operations.

### Key Concept

Dragging a file between folders can move or copy the file depending on
the location and keyboard modifier being used.

> Take a screenshot of File Explorer showing all the files inside the `CIS107\Documents` folder and the `CIS107\Images` folder. You must take a single screenshot showing both folders. Save your screenshot to use later in your final submission.


## Activity 5: Delete and Restore Files

**Skills:** Deleting files and using the Recycle Bin

### Tasks

1.  Create a file named:

``` text
delete_me.txt
```

2.  Delete the file.
3.  Open the **Recycle Bin**.
4.  Locate `delete_me.txt`.
5.  Restore the file.
6.  Verify that it has returned to its original location.
7.  Delete the file again.
8.  Empty the Recycle Bin.

### Questions

1.  What happens to a file when it is normally deleted?
2.  What is the purpose of the Recycle Bin?
3.  What is different about emptying the Recycle Bin?

> This activity does not require a screenshot. Answer the questions in the submission document.

## Activity 6: Search for Files

**Skills:** File Explorer search

Create several files with different names and then use the File Explorer search box to locate them. Use long and short file names such as `Homework_biology_fall_26.txt`.

### Tasks

Search for:

1. A specific filename.
2. All text files.
3. A file containing a particular word in its name.

* **Example search:**

``` text
*.txt
```

* **Then search for:**

``` text
notes
```

### Questions

1.  What happens when you search for `*.txt`?
2.  What happens when you search for `notes`?
3.  Does searching move or modify the files?

## Activity 7: Understand File Extensions

**Skills:** Identifying file types

Enable file extensions in File Explorer:

**View → Show → File name extensions**

Identify the extensions of common file types:

  File Type                           Extension
  ----------------------------------- -----------
  Microsoft Word document             `.docx`
  Microsoft Excel workbook            `.xlsx`
  Microsoft PowerPoint presentation   `.pptx`
  JPEG image                          `.jpg`
  PNG image                           `.png`
  Text file                           `.txt`
  PDF document                        `.pdf`

### Tasks

1.  Enable **File name extensions**.
2.  Locate several files on your computer.
3.  Record their file extensions.
4.  Explain why `report.docx` and `report.pdf` are different file types.

## Activity 10: File Management Challenge

**Skills:** Applying all previous file management skills

Create a folder containing the following files:

``` text
assignment1.docx
photo.jpg
notes.txt
presentation.pptx
old_assignment.docx
logo.png
spreadsheet.xlsx
readme.txt
```

The files should initially be placed together in one folder.

### Tasks

1.  Create appropriate folders.
2.  Rename files using consistent names.
3.  Move each file into the appropriate folder.
4.  Identify and remove unnecessary files.
5.  Search for a specific file.
6.  Sort the files by type.
7.  Enable file name extensions.
8.  Change the File Explorer view to **Details**.
9.  Demonstrate your final organized folder structure.
