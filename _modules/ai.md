## AI Chat Assistants

- [ChatGPT](https://chat.com/): General-purpose assistance, writing, coding, research, and problem-solving.
- [Gemini](https://gemini.google.com/): Google ecosystem integration, multimodal tasks, and productivity.
- [Lumo](https://lumo.proton.me/): Privacy-focused AI assistance and confidential conversations.
- [Leo](https://search.brave.com/ask): Privacy-focused AI assistance integrated into Brave Search.
- [Perplexity](https://www.perplexity.ai/): Web research, source citations, and finding current information.
- [Claude](https://claude.com/): Writing, document analysis, coding, and complex reasoning.
- [DeepSeek](https://chat.deepseek.com/): Reasoning, mathematics, and programming.
- [Microsoft Copilot](https://copilot.microsoft.com/): Microsoft ecosystem integration, productivity, and everyday assistance.
- [Meta AI](https://www.meta.ai/): Everyday conversations, image generation, and Meta platform integration.
- [Grok](https://grok.com/): General-purpose assistance, reasoning, and information related to X.
- [Mistral Le Chat](https://chat.mistral.ai/): General assistance, multilingual tasks, and document analysis.
- [Qwen Chat](https://chat.qwen.ai/): Reasoning, coding, multilingual tasks, and general assistance.
- [Poe](https://poe.com/): Accessing multiple AI models and chatbots through one platform.
- [Character.AI](https://character.ai/): Character-based conversations, roleplay, and interactive storytelling.
- [HuggingChat](https://huggingface.co/chat/): Exploring open models and conversational AI.
- [You.com](https://you.com/): AI-powered web search, research, and productivity.
- [Phind](https://www.phind.com/): Technical research, programming questions, and software development.

> **Distinction:** General-purpose assistants are designed for a broad range of tasks, while specialized or multi-model assistants focus on particular workflows or provide access to multiple AI models.
> - **General-purpose assistants:** ChatGPT, Gemini, Claude, Microsoft Copilot, DeepSeek, Grok, and Qwen Chat.
> - **Specialized or multi-model assistants:** Perplexity (research), Poe (multiple AI models), Character.AI (character conversations), HuggingChat (open models), Phind (programming), Brave Leo (privacy-focused browsing), and You.com (AI-powered search).

## Models vs. Applications

An **AI model** is the underlying machine learning system that generates, interprets, or transforms information. An **AI application** is the software interface that allows users to interact with AI models and use their capabilities to accomplish tasks.

- **Model:** The underlying AI technology that performs the computation. Examples include GPT, Claude, Gemini, Whisper, FLUX, and Stable Diffusion.
- **Application:** The software that exposes AI capabilities through a user interface, workflow, or API. Examples include ChatGPT, Cursor, MacWhisper, Midjourney, and Canva.

### Key Differences

| Characteristic  | AI Model                                                   | AI Application                                           |
| --------------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| Primary purpose | Performs AI inference or generation                        | Makes AI capabilities accessible and useful              |
| User interface  | May have no built-in interface                             | Usually provides a user interface or workflow            |
| Deployment      | Runs locally or on remote infrastructure                   | Runs locally, in a browser, or in the cloud              |
| Dependencies    | Requires compatible inference software or a hosted service | May use one or more models and other software components |
| Examples        | Whisper, FLUX, Stable Diffusion                            | MacWhisper, image-generation interfaces, Canva           |

### Examples of the Relationship

- **GPT → ChatGPT:** GPT models power capabilities available through the ChatGPT application.
- **Whisper → MacWhisper:** Whisper can transcribe speech, while MacWhisper provides a desktop interface for using transcription models.
- **FLUX → Image-generation applications:** FLUX models can generate images through compatible applications and interfaces.
- **Stable Diffusion → ComfyUI:** Stable Diffusion models can be loaded into ComfyUI to build visual generation workflows.

> **Important:** The distinction is not always absolute. Some products combine models, interfaces, orchestration systems, and other services. Some applications let users choose between multiple models, while some models are available through several different applications. Product names may also refer to both a model family and the service built around it.
